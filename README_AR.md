# موقع أستاذ الرياضيات — لوحة إدارة سحابية

المشروع يحافظ على تصميم الموقع الأسود والأحمر، ويضيف لوحة تحكم مخفية لإدارة الملفات والمذكرات والروابط عبر واجهة رسومية بدون كتابة كود في الاستخدام اليومي.

## ما الذي يفعله؟
- عرض الملفات والمذكرات والروابط لكل الزوار.
- رفع ملف من لوحة التحكم إلى Supabase Storage (حد 20MB).
- إضافة روابط خارجية وحذف العناصر المنشورة.
- حفظ رقم واتساب في قاعدة البيانات وتحديث أزرار التواصل.
- صلاحيات الإدارة مبنية على Supabase Auth وRow Level Security (RLS).
- لا توجد روابط سوشيال خارجية في الواجهة عدا واتساب؛ الروابط التي تضيفها أنت ستظهر في قسم الروابط.

## 1) إنشاء مشروع Supabase
1. افتح https://supabase.com وأنشئ مشروعًا جديدًا.
2. من Project Settings > API انسخ **Project URL** و **anon/public key** (أو publishable key).
3. افتح `config.js` وضع القيم مكان `YOUR-PROJECT` و `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY`.
4. لا تضع `service_role` key في الواجهة أبدًا.

## 2) إعداد قاعدة البيانات والتخزين
1. من Supabase افتح SQL Editor.
2. انسخ محتوى `supabase_setup.sql` بالكامل وشغّله.
3. من Authentication > Users أنشئ مستخدم الإدارة بالبريد وكلمة مرور قوية.
4. انسخ UUID للمستخدم من صفحة Users.
5. في SQL Editor شغّل هذا الأمر بعد استبدال UUID:
   ```sql
   insert into public.site_admins (user_id)
   values ('YOUR_ADMIN_USER_UUID');
   ```
6. عيّن رقم واتساب أولي (أرقام فقط مع مفتاح الدولة)، أو أضفه لاحقًا من لوحة التحكم:
   ```sql
   insert into public.site_settings(key, value)
   values ('whatsapp', '201xxxxxxxxx')
   on conflict (key) do update set value = excluded.value, updated_at = now();
   ```

## 3) تشغيل الموقع محليًا
لا تعتمد على فتح `index.html` عبر `file://` عند اختبار تسجيل الدخول؛ استخدم خادمًا محليًا مثل VS Code Live Server أو:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## 4) استخدام لوحة الإدارة
افتح `http://localhost:8000/#admin`، ثم سجّل الدخول بحساب الإدارة الذي أنشأته. الرابط المخفي وحده ليس حماية؛ الحماية الفعلية عبر Supabase Auth وRLS.

من لوحة الإدارة:
- **إضافة ملف / مذكرة:** اختَر الملف واكتب اسمه ثم انشر.
- **إضافة رابط:** أدخل الاسم والرابط الكامل.
- **إدارة المحتوى:** احذف العناصر المنشورة.
- **إعدادات واتساب:** غيّر الرقم الذي يظهر في الموقع.

## 5) النشر على الإنترنت
ارفع الملفات `index.html`, `app.js`, `config.js` إلى استضافة static مثل Netlify أو Vercel أو Cloudflare Pages. بعد النشر:
- أضف نطاق الموقع في إعدادات Authentication > URL Configuration داخل Supabase.
- اضبط Site URL وRedirect URLs على نطاقك.
- اختبر تسجيل الدخول والإضافة والحذف من جهاز آخر.
- احتفظ بكلمة المرور قوية، ولا تشارك حساب الإدارة.

## ملاحظات أمنية مهمة
- Project URL وanon/publishable key مسموح ظهورهما في الواجهة بشرط إعداد RLS كما في ملف SQL.
- **لا تضع service_role key أو أي سرّ إداري في `config.js`.**
- ملفات bucket عامة للتحميل؛ أي شخص لديه رابط الملف يستطيع فتحه. صلاحية الرفع والحذف محصورة في المستخدم الموجود في `site_admins`.
- حاليًا النظام يدير المحتوى والإعدادات والملفات. غيّر أرقام الإحصائيات والنصوص الثابتة داخل `index.html` إذا أردت تخصيصها.
- هذا المشروع قالب جاهز للربط، لكنه لا يصبح متصلًا بقاعدة بياناتك حتى تنفذ إعدادات Supabase أعلاه.
